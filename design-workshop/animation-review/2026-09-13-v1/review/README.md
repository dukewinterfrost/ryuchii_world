# Digital Companion · 18 animation candidates

Open `index.html` to review the motion. Use replay, frame stepping, speed, character filtering, and approved-pose comparison. One-shot previews can repeat with a hold; their GIF and timing exports preserve the one-shot behavior.

Each action includes numbered 128×128 transparent PNG frames under `frames/`, a transparent horizontal strip, a six-column sheet, a GIF preview, and JSON timing with paths and SHA-256 hashes. There are 175 selected frames across the 18 clips. All animations are pending motion review.
