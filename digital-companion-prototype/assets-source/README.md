# Source plans, not approved art

`agumon/combat-v1/source-plan.json` declares eight facings and eight combat
actions. One-frame entries are unfilled source-binding templates to expand into
real animation sequences, not finished battle sprites. `forest-arena/forest-v1`
declares the matching forest arena footprint and generation brief.

No new artwork or human approval is implied by these plans. Ingest key poses
(or the environment composition sample), obtain human review, then ingest
completed frames. Final review is a separate hash-bound gate before promotion.
Existing companion/habitat runtime art remains unchanged until that happens.

See `docs/SPRITE_PIPELINE.md` for commands and field contracts.
